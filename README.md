## Pages

- **Services** (`services.html`) — linked in the nav, not yet built.

## Setup

1. Download or clone the project files.
2. Make sure `car-hire.jpg` is in the same folder as `index.html`, and that the filename matches exactly (no spaces).
3. Create a `style.css` file in the same folder to style the page (currently linked but not included).
4. Open `index.html` in a browser to view the site.
